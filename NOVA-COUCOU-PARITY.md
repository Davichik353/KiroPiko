# Сохранение возможностей Coucou в NOVA

Проверка 14 октября 2026: GitHub `main` и локальная исходная база совпадают: `b6d2d00ac6c3934187a0656e287039f4cbad71e5`. Репозиторий Coucou уже полностью находится в этой папке; повторное копирование поверх NOVA перезаписало бы наши изменения.

`npm run check:preserved` из `windows/` проверяет сохранение исходных файлов Windows-модуля, Tauri-команд, каталога инструментов, провайдеров и полей настроек. Подтверждено: 97 исходных команд, 29 записей каталога, 7 провайдеров, 39 полей настроек, 116 исходных файлов. Команда обнаруживает удаление контрактов; она не доказывает правильность поведения, доступность сервисов или совместимость функций macOS с Windows.

## Новые возможности NOVA поверх основы

Персонаж и прогулки, футбол, System Doctor, Voice/Vision, Windows-медиасессии, история событий, размер персонажа, проверка подключений, экспорт диагностического отчёта, обучение первого запуска. Они не заменяют исходные команды.

## Что нельзя считать уже перенесённым из macOS

В README Coucou часть функций явно относится к macOS: криптопортфель, Mail.app и отправка почты, окно как контекст через перетаскивание, Siri, iPhone Live Activities/виджеты, голосовая фраза «OK Coucou», полный Apple Music/Spotify control (seek/shuffle/repeat), «Always» с постоянными правилами разрешений. Swift-код сохранён в репозитории, но не исполняется в Tauri-приложении Windows. Для эквивалентов нужен отдельный перенос и тестирование. Windows-медиасессии KiroPiko сейчас реализуют метаданные, play/pause/previous/next, seek/shuffle/repeat при поддержке плеером; этот backend ещё не собран и не проверен в нативном приложении; голос запускается по кнопке. Нельзя объявлять полное равенство всех платформ только на основании сохранённых файлов.

Указанные пробелы остаются в объёме запроса пользователя о полном переносе. До их реализации и нативных проверок задача «все функции Coucou в NOVA Windows» не завершена. Текущий результат — сохранённая Windows-основа и добавления NOVA, а не подтверждённая стопроцентная совместимость.
