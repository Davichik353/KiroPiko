# Обязательные функции NOVA

Утверждённый пользователем список. Новые персонажи, интерфейс, System Doctor и Voice/Vision добавляются поверх этой основы. Изменения дизайна не должны удалять или подменять её рабочие механизмы.

| Сохраняем | Точки подключения в `windows/` | Проверка |
| --- | --- | --- |
| Наблюдение за AI-агентами | `src/island/hooks.ts`, `src/core/state.ts`, `src-tauri/src/pipe.rs`, `hook/` | Активные сессии Claude Code, Codex, Cursor и других подключённых агентов; обработчики остаются подключены в `src/main.ts` |
| Allow / Deny | `src/views/views.ts`, `src/core/bridge.ts`, `src-tauri/src/pipe.rs` | Решение относится к ожидающему запросу; сворачивание панели не означает согласие |
| Ответы на вопросы | `src/island/hooks.ts`, `src/views/views.ts`, `src/core/bridge.ts` | Варианты AskUserQuestion, одиночный/множественный выбор и возврат к терминалу |
| Изменения файлов | `src/core/diff.ts`, `src/views/diff.ts`, `src/views/ticker.ts` | Имена файлов, +/− строк и открытие разницы кода |
| Переход к сессии | `src/core/bridge.ts`, `src-tauri/src/session_window.rs` | Открытие окна сессии либо предусмотренный fallback в редактор |
| Чат с AI | `src/views/chat.ts`, `src/core/providers.ts`, `src-tauri/src/chat.rs` | Выбор поддерживаемого подключения, история и обработка ошибок |
| Перетаскивание файлов | `src/upload/`, `src/core/bridge.ts`, `src-tauri/src/files.rs`, `src-tauri/src/webview_drop.rs` | Реальный drop авторизует импорт файла; изображение передаётся поддерживающей его модели после отправки вопроса |
| Уведомления о работе | `src/island/hooks.ts`, `src/island/island.ts` | Завершение, ошибки, вопросы и ожидающие разрешения отражаются в панели и состоянии персонажа |
| Компактная панель | `src/island/fsm.ts`, `src/island/island.ts`, `src/core/layout.ts` | Клик, настройка открытия по наведению, сворачивание и закрепление |
| Горячие клавиши и трей | `src/core/shortcuts.ts`, `src/island/shortcuts.ts`, `src-tauri/src/shortcuts.rs`, `src-tauri/src/tray.rs` | Существующие действия и пользовательские сочетания сохраняются |
| Настройки и ключи | `src/settings/`, `src-tauri/src/settings.rs`, `src-tauri/src/secrets.rs` | Предпочтения и языки сохраняются; ключи идут через существующее защищённое хранилище ОС |

## Что подтверждено сейчас

Обработчики и команды этих функций сохранены в исходном коде. Пройдены сборка TypeScript/Vite и 403 теста, включая обработку событий агентов, чат, вопросы, diff, FSM, горячие клавиши и настройки языков. Новые иллюстрации подключены через адаптер персонажа.

Это не подтверждение полного нативного сценария. Для выпуска нужно отдельно пройти каждый пункт в собранном Windows-приложении: реальная сессия агента → событие → панель → решение/ответ → продолжение сессии. Дополнительно проверить реальный drop, окно терминала, горячие клавиши вне приложения, трей, хранение ключей и подключённую модель. Cargo и Visual Studio C++ Build Tools пока отсутствуют в текущем окружении.

Браузерное превью позволяет проверить интерфейс и внешний вид. Оно не устанавливает хуки, не открывает локальные программы, не хранит API-ключи и не выполняет нативные команды Windows. Только отдельные настройки внешнего вида сохраняются в браузере.

## Правило для следующих изменений

Перед заменой или удалением существующего модуля найти его обработчики событий, вызовы Bridge и тесты. Подключить замену с тем же поведением, пройти затронутые тесты и соответствующий нативный сценарий. Если проверка недоступна, явно оставить статус «не проверено», а не объявлять функцию готовой.
