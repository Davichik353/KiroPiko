# KiroPiko: проверка перед релизом

Обновлено 15 октября 2026. Статусы разделяют проверку кода, прямой вызов системного API и нажатие в установленном приложении. Рабочее окно сейчас запущено из target/debug: это dev-сборка, а не доказательство установки.

## Результаты текущего запуска

- Полные тесты Rust: 413 приложения + 30 hook прошли; 2 системных теста пропущены.
- Последняя сборка интерфейса и 416 тестов прошли после изменения походки.
- Сохранение Coucou: 97 команд, 29 записей каталога, 7 провайдеров, 39 исходных настроек и 116 файлов подтверждены.
- Прямой запрос Windows обнаружил ru.yandex.desktop.music в состоянии Paused. Windows не предоставляет для него shuffle/repeat; отдельный UI Automation адаптер требует проверки нажатий из островка.
- Прямой запуск System Doctor вернул CPU, RAM, диски и сеть. Это не проверка кнопки экспорта или AI-объяснения. Высокая нагрузка во время компиляции не считается самостоятельной неисправностью компьютера.
- Обнаружен один активный физический монитор. Несколько мониторов и реальные изменения DPI пока не проверены.
- Средства Windows Sandbox и команда Hyper-V Get-VM в доступной среде не обнаружены. Проверка чистой Windows здесь не выполнена.
- Инструмент ввода не смог нажать прозрачное окно KiroPiko: точка определилась над ChatGPT. Обход защиты не выполнялся; нативные нажатия не помечены успешными.

## Отдельный сценарий чистой Windows

Использовать тестовую VM со снимком или отдельный компьютер без Rust, Node и Visual Studio. Скопировать сборку и её SHA256, установить, запустить без dev-сервера, проверить матрицу, перезагрузку и удаление. Отдельно проверить среду без WebView2 с учётом сетевого доступа. Факт сборки MSI/EXE не заменяет этот сценарий. Тестировать без пользовательских документов и настоящих секретов; для почты нужен согласованный адрес и тестовое вложение.

## За пределами текущего релиза

Универсальная браузерная музыка, камера, загрузка сторонних плагинов и автоматические исправления System Doctor остаются будущей работой. Незавершённые настройки ширины островка и режим «Не мешать» также нельзя отмечать готовыми.

## Дополнительная проверка интерфейса
В браузерном превью проверены открытие музыки кликом по капсуле и переходы в инструменты, почту, System Doctor, Developer Mode и AI-чат. Doctor явно объясняет отсутствие системного доступа в браузере. Подготовлен черновик для тестового получателя; письмо не отправлено, отправитель и Resend ещё не подтверждены. Тестовое вложение: D:/NOVA/.tools/kiropiko-mail-test.txt. Скриншот: kiropiko-mail-test-draft.png.


В браузере дополнительно проверены 800×600 и 640×480: панель инструментов помещается, нижние действия доступны прокруткой. Это не тест DPI Windows. Временный размер браузера сброшен, тестовая вкладка закрыта. Отправка письма не выполнялась: подтверждённый отправитель не указан; секреты не включены в отчёт.
