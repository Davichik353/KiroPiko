# KiroPiko: поддержка, выпуски и Apricot After Dark

## Направление оформления

Основа — существующие карточки KiroPiko и рекомендации Refero Color / Craft Details: нейтральные поверхности, один цвет основного действия, контрастный текст и заметный keyboard focus. Референсы внутри продукта: капсула, Settings, Android Panel/PillButton. Из персонажа взяты тёмно-сливовая шляпа и тёплые глаза; фон не окрашен в яркий фиолетовый. Палитра: design/kiro/palette.json. Ошибки, ожидание и завершение сохраняют свои смысловые цвета. Сияние Android уменьшено до 16%, а контраст проверяется тестами даже при белом idle-оттенке.

## Что сломалось?

Windows: Настройки → Помощь и обновления. Версия, ОС/архитектура, состояние двух переключателей и категории недавних ошибок. Просматриваются последние 1500 строк ограниченного локального журнала, но в отчёт попадают только числа AI/Phone/Voice/Other. Ошибки запросов чата и списка моделей записывают только фиксированную категорию без сообщения сервера.

Android: Настройки → Помощь и обновления. Версия, API Android, состояние связи, количество задач/разрешений/вопросов, число ошибок AI/связи после запуска и результаты проверок как OK/FAILED/SKIPPED. Исходные ошибки и личные данные не копируются.

Оба отчёта видны до копирования. Ничего автоматически не отправляется; в них нет ключей, QR-кодов, адресов компьютера, переписки, команд или названий проектов.

## Обновления

Только по нажатию: публичный API выпусков Davichik353/KiroPiko, максимум 512 КБ, таймаут. Выбирается установщик своей платформы по числовой версии, допускаются preview-выпуски. Имена файлов и адрес скачивания проверяются; адрес должен вести в releases/download этого репозитория. AI-ключи и данные сопряжения не используются.

Скачивание открывает браузер; Windows-установщик запускается пользователем. На Android скачанный APK открывается из «Загрузок», разрешение на установку и само подтверждение обрабатывает Android. Нет фоновой установки, обхода защиты ОС или молчаливого перезапуска. Это помощь с ручным обновлением, не silent updater.

## Нужно твоё решение

Расширен существующий Waiting Alert, сохраняются receiver и установленные виджеты. Старейший живой вопрос/запрос среди всех агентов показывает имя агента, проект (только если он уже передан включённой на ПК функцией деталей), количество ожиданий и системный Chronometer. Без проекта явно сказано, что он не передан. Счётчик не требует нового таймера или фонового опроса приложения. При разрыве связи сведения запроса скрываются.

Нажатие использует существующий явный immutable PendingIntent и открывает нужную сессию через LaunchActivity. Сам виджет не разрешает команды; проверка актуальности и биометрия остаются в приложении.

## Проверка

Браузерное превью: открытые настройки и капсула проверены визуально, кнопки отчёта/обновлений в браузере объясняют необходимость установленного Windows-приложения; ошибок консоли нет. Предпросмотр не выдаётся за проверку нативных команд. Полный тест новой установленной версии на физическом телефоне остаётся за пользователем.

Финальные локальные проверки: Windows UI — 430 passed; Rust — 423 passed + 30 hook passed, 2 ignored; Android — 826 passed, 44 skipped. Контракты Coucou сохранены. Android assembleDebug/lintDebug успешны (0 errors, 51 warnings), подпись финального APK проверена. Windows NSIS/MSI 0.4.2 собраны успешно. Физический телефон и полный сценарий установки поверх существующего приложения не тестировались автоматически.

Проверка опубликованного выпуска: kiropiko-preview-2026-10-16 содержит Windows EXE/MSI, Android APK и SHA256SUMS.txt. Выполнен реальный AppUpdates.check из скомпилированного Android-кода на JVM 17 без ключей/авторизации: для старой версии найден APK 0.1.2-preview, для текущей версии newer=false. Это проверка клиентского кода и публичного API, не проверка установки на телефоне.
