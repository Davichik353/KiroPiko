# NOVA development status — 2026-10-14

Source: https://github.com/Louis-CFM/coucou.git. Local base and upstream HEAD both matched `b6d2d00ac6c3934187a0656e287039f4cbad71e5` at verification time. NOVA changes are local and uncommitted. The Git remote still points to the original project; nothing has been pushed.

The user-approved preservation requirements and code map are in [NOVA-CORE-CONTRACT.md](NOVA-CORE-CONTRACT.md). All eleven core capabilities must remain available as NOVA evolves; native verification is a release requirement.

## Implemented

- `windows/src/nova/character/`: sprite character adapter and greeting, nine illustrated states, original accessory overlays. Existing event and animation lifecycle retained. Main panel, desktop, mini companions, upload and recap rendering use NOVA. Sprites use spring motion, ambient breathing and a two-frame blink; independently rigged eyes and facial movement remain future work.
- `windows/src/nova/doctor/`: on-demand CPU, RAM, local disk space and adapter connection status with deterministic explanations. One sample is not a hardware health assessment or internet connectivity test. No repair commands exist.
- `windows/src/nova/developer/`: session overview and switching into existing agent detail/approval views. Existing Coucou hooks and recap storage remain. No fake percent-complete value is generated.
- `windows/src/nova/assistant/`: a reviewed diagnostic question draft using the existing model chat. No diagnostics are automatically sent to a provider.
- `windows/src/nova/voice/`: one-shot local Windows speech dictation, cancellation that discards late transcripts, commands for Notepad/Calculator/Explorer and opening Doctor. App launch is proposed and requires a click. Recognition depends on installed Windows speech languages; this machine exposed en-US.
- Vision: primary-screen screenshot capture in the native backend; attach locally, then explicitly send through existing Anthropic image chat. Permission defaults off. No continuous screen recording.
- Settings: separate persisted microphone/screenshot permissions, both off by default, enforced in Rust too. Disabling microphone stops current recognition.
- Original synthesized audio under `windows/public/sounds/`, generated by `windows/scripts/gen-nova-sounds.mjs`. Vite no longer reads the original macOS sound folder.
- Original N monogram PNG/ICO set generated by `windows/scripts/gen-icons.mjs`; NOVA panel/tray/window branding. Original MIT notices included in bundle resources for core and phone-link code.

## Browser feedback update

- Added idle adventures: after two minutes without NOVA interaction and active agent work, a 28-second walk/football visit can start. Manual start and home controls live in Tools; automatic visits can be disabled in Settings. Reduced-motion preference suppresses automatic visits.
- Browser preview confines the companion to the browser viewport. Native Windows code moves only NOVA's own landed window within the current monitor work area, yields to user dragging/flights and uses the existing desktop lifecycle. Native roaming is not yet tested through Tauri.
- Browser manual launch, walking, football phase and automatic return were visually verified. Evidence: `nova-walking-preview.jpg` and `nova-football-preview.jpg` in the repository root.
- Play stops for agent work/requests, voice, pause or an active chat/diagnostic view. Browser play also stops when the tab becomes hidden. No other applications, files or inputs are controlled by play.

- Compact character now uses upper-body art with both forearms/hands resting on the capsule edge. Increased top clearance and native panel height keep hair and expanded content within the window.

- Approved module scope: NOVA-V01-SCOPE.md. Four primary character modes now map to rest, listening, thinking and speaking. Existing agent alerts remain intact.
- Chat has explicit read-aloud and stop controls. Speech uses local OS voices only and stops on a new question, dictation or leaving chat. Real audio output and available voices require testing in the target Windows runtime.

- Resend, n8n, Vercel and GitHub now have four distinct illustrated companions. Selecting a service also shows its companion in the main overview slot.
- NOVA now breathes, sways, follows cursor direction with its pose and blinks using a dedicated aligned two-frame asset. Visible idle animation keeps its loop alive; hidden panels park it. Reduced-motion preference suppresses ambient motion.
- Browser settings open as a real preview page, with return navigation and a clearly marked capability banner. Only selected non-secret appearance preferences are stored in browser localStorage; native credentials/hooks are not simulated or saved there.
- Native launch buttons in browser mode display an explanation instead of silently doing nothing. Failed native program launch results also produce a notice.
- Integration pills are keyboard-focusable buttons.

## Not yet verified / remaining

- Native Rust/Tauri compilation, executable and installer: Cargo/Rust and Visual Studio C++ build tools are absent in this environment. Native voice, capture and launch code has not been exercised through Tauri.
- Live agent approval round trip and model responses require running the native app and configured provider credentials.
- Voice file search, arbitrary program integration, selected-text acquisition, screenshot preview/redaction, multiple monitor capture, full task-history UI and third-party plugin loading are not implemented.
- Full-body outfit artwork, independently rigged facial motion, complete localization of NOVA text and matching the reference character resting hands on the capsule remain design work.
- Release rebrand still needs a separate application identifier, isolated storage/credential/hook namespace, versioning, remaining Coucou/Mochi strings in legacy settings/recap copy and platform packaging audit. The source tree still contains original artwork in other platform/documentation folders. Do not package the whole repository as NOVA release assets.
- Existing user-created Docker/Compose files still assume an absent Node server entry point; they are not used for native Tauri development.
- No commercial release, signing, distribution, purchase or external publication has occurred.

## Run the frontend preview

```powershell
Set-Location D:\NOVA\coucou\windows
npm ci
npm run dev
```

Open http://127.0.0.1:1420/. Browser mode deliberately cannot access Windows metrics, microphone, screen or native launch commands. `npm run dev` no longer invokes Cargo; native Tauri commands build the hook explicitly.

With Rust and Windows C++ build tools installed, the native entry point is `npm run tauri -- dev`; installer command is `npm run pack`. These native commands have not been verified here.

Review original notices in `LICENSE`, `android/LICENSE` and `LICENSE-ASSETS.md` before distributing the fork; the original code and original artwork have different terms.
