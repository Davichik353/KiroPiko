# Новые функции KiroPiko — 16 октября 2026

В Windows добавлены объяснение видимой команды перед Allow, итог завершённой задачи в локальной истории, диагностика модели/хуков агента/связи с телефоном и общий список ожидающих решений. В Android добавлены тот же список решений, объяснение после раскрытия точной команды, одно напоминание через 45 секунд и раздел установки девяти существующих виджетов.

В чате Windows кнопка «Авто» выбирает модель из актуального списка выбранного провайдера. Выбранная модель указана у ответа. Провайдер не меняется; стоимость и бесплатная квота автоматически не проверяются. Настройка не включает автоматический выбор в Android и не повторяет запрос через другой сервис при ошибке.

## Практические ограничения

- Объяснение команды основано на её тексте. Содержимое запускаемых скриптов не исследуется, безопасность не гарантируется.
- Итог показывает полученные от агента данные. Упоминание теста не считается доказательством успешного завершения: проверка кода возврата явно не подтверждена.
- Список объединяет ожидающие сессии, сохраняя существующее ограничение одного активного разрешения через островок. Остальные и неподдерживаемые запросы решаются в терминале; новые кнопки Allow для них не создаются.
- Напоминание действует для полученных телефоном действующих запросов, один раз за запрос в процессе приложения. Оно учитывает тихие часы телефона и системный Android «Не мешать». Режим тишины Windows отдельно на телефон не синхронизирован.
- Проверка модели запрашивает список моделей, а не генерирует платный тестовый ответ. Готовность хуков не доказывает работу конкретного внешнего агента.
- Android сам подтверждает размещение виджета; поддержка закрепления зависит от домашнего экрана. Если прямое закрепление недоступно, показан ручной способ.

## Проверка

Автоматические проверки Windows: 423 теста интерфейса; 415 тестов приложения и 30 тестов hook, без ошибок (два теста проигнорированы). Сборка веб-интерфейса и проверка сохранения исходных возможностей успешны.

Android: 864 теста, из них 820 успешны и 44 пропущены; APK и lint собраны успешно. Lint: 0 ошибок, 51 предупреждение.

Реальные вызовы платных API, уведомления на физическом телефоне, закрепление виджетов в разных лаунчерах, несколько физических мониторов и установка на чистую Windows этим прогоном не подтверждены.
